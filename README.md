# 强化学习学习笔记与实验

以《动手学强化学习》为主线，记录概念理解、数学推导、代码实现、小实验和待解决的问题。

## 学习资料

- 主线教程：[动手学强化学习](https://hrl.boyuai.com/)
- 理论参考：[Sutton & Barto, Reinforcement Learning: An Introduction](https://mitpress.mit.edu/9780262039246/reinforcement-learning/)
- 进阶课程：[UC Berkeley CS 285](https://rail.eecs.berkeley.edu/deeprlcourse/)
- 代码参考：[CleanRL](https://docs.cleanrl.dev/)
- 实验环境：[Gymnasium](https://gymnasium.farama.org/)

## 目录约定

后续按需创建，不预填完整课程答案：

```text
chapters/    # 按教材章节整理概念、推导、代码和实验记录

```

建议第 2 章多臂老虎机使用 `chapters/02_multi_armed_bandits/`。

## 学习记录方式

1. 用自己的话说明问题和关键概念。
2. 为关键公式写出推导和一个数值例子。
3. 运行或实现最小实验，记录预期与实际结果。
4. 每次只改变一个因素，说明观察到的差异。
5. 标明未理解、未验证和后续想追问的问题。

## 实验记录

记录环境版本、算法、超参数、随机种子、评估方式和结果；运行成功不等于理解算法，多次重复实验后再判断效果。

## 来源与边界

个人学习仓库，不是课程官方仓库。引用或改编代码时注明原始来源并遵守其许可证；不整本复制教材。尚未运行的代码、尚未完成的实验不标为已验证。
